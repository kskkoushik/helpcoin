

# 🌍 **HelpCoin** – Transforming Kindness into Financial Freedom  

HelpCoin is a **game-changing decentralized web app** that reshapes how humanity and the economy intersect. It creates a powerful, trustless ecosystem where users can offer or request help, earning **HelpCoins**—a digital currency directly tied to real-world value.  

Imagine turning simple acts of kindness into actual income, with HelpCoins seamlessly convertible into fiat money. This platform revolutionizes how we view service, transforming goodwill into a legitimate financial asset.  

---

## 🚀 **Core Features**  
✅ **Decentralized Ecosystem:** Built on a Solidity-based smart contract backend for maximum security and transparency.  
✅ **Earn Through Engagement:** Earn HelpCoins by offering services, requesting help, or interacting with platform content.  
✅ **Seamless Fiat Conversion:** HelpCoins can be converted into real-world currency through integrated payment gateways.  
✅ **Trustless Transactions:** Eliminates the need for middlemen, ensuring peer-to-peer transparency.  
✅ **Community Driven:** Fosters a global community powered by collaboration and financial empowerment.

---

## 🌟 **How It Works**  
1. **Sign Up & Connect Wallet**  
   - Create an account and securely connect your wallet using MetaMask.  

2. **Offer or Request Help**  
   - Engage with the community by offering or requesting help.  
   - Earn HelpCoins directly into your wallet.  

3. **Earn HelpCoins Through Engagement**  
   - Watch videos and engage with content to unlock additional HelpCoin rewards.  

4. **Convert HelpCoins to Fiat**  
   - Exchange HelpCoins for real-world currency through integrated payment gateways.

## 📥 **Installation and Setup**  
### 1. Clone the Repository  
```bash
git clone https://github.com/your-username/helpcoin.git
```

### 2. Install Dependencies  
#### Frontend  
```bash
cd frontend  
npm install  
npm start  
```

#### Backend  
```bash
cd backend  
pip install -r requirements.txt  
flask run  
```

### 3. Set Up Environment Variables  
Create a `.env` file in both the frontend and backend directories with the following values:  

#### Frontend `.env`  
```bash
REACT_APP_API_URL = "http://localhost:5000"
REACT_APP_WEB3_PROVIDER = "https://mainnet.infura.io/v3/your-infura-key"
```

#### Backend `.env`  
```bash
SECRET_KEY = "your-secret-key"
MONGO_URI = "your-mongodb-uri"
WEB3_PROVIDER = "https://mainnet.infura.io/v3/your-infura-key"
```

### 4. Start the App  
Navigate to:  
```bash
http://localhost:3000
```
